# GIFFit

**5MB 안에서 가장 선명하게.**

GIFFit은 영상 파일을 로컬에서 분석하고, 파일마다 실제 후보 GIF를 반복 생성해 설정한 용량 이하에서 가능한 큰 해상도를 효율적으로 찾는 Windows 앱입니다.

## 빠른 사용법

1. 받은 ZIP의 압축을 풀고 `GIFFit_5MB` 폴더 안의 `GIFFit_5MB.exe`를 실행합니다. EXE 옆의 `_internal` 폴더는 이동하거나 삭제하지 마세요.
2. **영상 추가**에서 MP4, MOV, MKV, AVI, WebM 또는 M4V 파일을 선택합니다.
3. 파일당 제한을 확인합니다. 기본값과 최대값은 정확히 `5.00 MB = 5,000,000 bytes`이며 더 작은 상한도 지정할 수 있습니다.
4. 원본 손상을 가장 줄이려면 기본값인 **화질 우선 · 손실 최소화**를 사용합니다.
5. 저장 위치를 선택하고 **변환 시작**을 누릅니다.
6. 완료된 GIF는 `원본이름_5MB.gif`로 저장됩니다.

## 기본 동작

- 원본 파일은 수정하지 않습니다.
- 모든 원본 프레임과 재생 순서를 우선 유지합니다.
- GIF가 지원하지 않는 오디오는 제거됩니다.
- 무한 반복 GIF를 생성합니다.
- 해상도마다 새 256색 팔레트를 만들고, 고품질 디더링과 용량 최적화를 적용합니다.
- 최종 파일을 전체 디코딩하고 프레임 수, 반복, 크기를 검증한 뒤에만 저장합니다.

## 품질 모드

- **화질 우선 · 손실 최소화**: 추가 손실 최적화를 사용하지 않습니다. 같은 제한에서 해상도가 더 낮아질 수 있습니다.
- **균형 · 선명도와 화면 크기 조화**: 낮은 강도의 GIF 최적화로 선명도와 해상도를 절충합니다.
- **해상도 우선 · 더 큰 화면 크기**: 약간 더 강하게 최적화해 더 큰 해상도를 시도합니다.

## 알아둘 점

- GIF는 최대 256색이고 프레임 시간 단위가 10ms이므로 원본 영상과 완전히 같을 수 없습니다.
- 길거나 움직임이 매우 많은 영상은 모든 프레임을 유지하면 결과 해상도가 작아질 수 있습니다.
- 기본 안전 여유를 켜면 가능한 경우 업로드 서비스의 반올림이나 부가 처리에 대비해 제한보다 약 2% 작게 만듭니다. 모든 프레임을 유지한 최소 해상도가 안전 목표보다 크면, 5MB 하드 상한 안의 결과를 우선 보존합니다.
- 이 실행 파일은 코드 서명이 없어 Windows SmartScreen 경고가 표시될 수 있습니다.

## 개인정보

영상은 네트워크로 업로드되지 않으며 모든 처리는 PC 안에서 수행됩니다.

## 지원 환경

- Windows 10/11, 64비트
- 별도 Python 또는 FFmpeg 설치 불필요
